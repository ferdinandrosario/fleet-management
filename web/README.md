# Web Admin Application (React + TypeScript + Vite)

The web administration panel for Super-Admin platform metrics and Owner fleet management.

## Setup & Running

```bash
# Install dependencies
npm ci

# Run development server (http://localhost:5173)
npm run dev

# Run typecheck
npm run typecheck

# Run unit tests
npm test

# Production build
npm run build
```

## Tech Stack

- React 19.2 (Vite)
- TypeScript 7.0
- Tailwind CSS 4.3.3
- Vitest 4.1.10
